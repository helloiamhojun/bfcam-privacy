남친카메라 개인정보처리방침

시행일: 2026년 11월 13일

남친카메라(이하 "앱")는 사진을 잘 찍도록 화면에 구도를 안내하는 카메라 앱입니다. 이 방침은 앱이 어떤 정보를 다루는지 설명합니다.

1. 앱이 직접 수집하는 개인정보

앱은 회원가입이 없고, 이름·연락처·위치 같은 개인정보를 수집하거나 서버로 보내지 않습니다. 개발자는 별도의 서버를 운영하지 않습니다.

2. 기기 안에서만 처리하는 정보

정보쓰는 곳저장 위치
카메라 화면과 찍은 사진촬영, 구도 안내(사람 위치 인식)찍은 사진만 이 기기의 Pictures/BfCam 폴더
사용자가 고른 예시 사진사람 윤곽(실루엣)을 만들어 화면에 겹쳐 보여 줌저장하지 않음
기울기·밝기 센서 값수평·각도 안내, 어두운 곳 판단저장하지 않음

이 정보는 기기 밖으로 보내지 않습니다. 사람 위치 인식과 윤곽 만들기는 기기 안에서 실행되는 Google ML Kit로 처리합니다.

3. Google ML Kit가 보내는 정보

앱에 포함된 Google ML Kit는 기능 개선과 오류 진단을 위해 다음 정보를 Google에 보냅니다. 사진이나 카메라 화면의 내용은 보내지 않습니다.

  • 기기 정보(기기 모델, 운영체제 버전 등), 앱 정보(패키지 이름, 앱 버전)
  • 성능 지표, 기능 설정, 입력·출력 크기, 오류 코드
  • 설치별 식별자 (사용자나 기기를 특정하기 위한 것이 아님)

이 정보는 HTTPS로 암호화해 전송되며, Google은 이를 제3자에게 넘기지 않는다고 밝히고 있습니다. 자세한 내용은 ML Kit 데이터 공개와 Google 개인정보처리방침을 확인해 주세요.

4. 권한

권한이유

인터넷, 네트워크 상태Google ML Kit의 정보 전송 (3항)

사진을 고를 때는 Android 사진 선택 도구를 써서, 앱이 사진첩 전체에 접근하지 않습니다.

5. 보관과 삭제

앱이 찍은 사진은 사용자의 기기에만 있고, 사용자가 갤러리에서 직접 지울 수 있습니다. 앱을 지워도 찍은 사진은 남습니다. 앱 안의 고르기 화면에서 고르지 않은 사진은 사용자가 "남기기"를 누를 때 지워집니다.

6. 아동

앱은 만 14세 미만 아동을 대상으로 하지 않습니다.
